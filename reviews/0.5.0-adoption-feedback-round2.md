## Blockers

### B1. Fail-closed redaction does not cover `image` — secret pixels are republished under a `redacted:true` stamp
`src/index.ts:647` (draw gate), `src/index.ts:697–702` (emission) — lens: correctness — **CONFIRMED** (adversarially verified by the review; independently re-reproduced by execution during this triage: `schematic({wiring:[{tag:'div', secret:true, image:'data:...SECRETPIXELS==', ...}]})` emits `<image href="data:...SECRETPIXELS==">` while the caption reads `<div> [withheld]`).

The `drawImage` gate checks only `!structural` and the `data:` prefix — no `w.secret` check. The G1 fail-closed block (src/index.ts:581–589) covers label/text/value/placeholder/href only, so the code's own stated invariant ("`redacted` must never co-occur with the facts it claims were withheld") is violated for the highest-bandwidth withholdable fact: a captured screenshot. The README spec's secret row omits `image` from the fail-closed list, and the G1 test never exercises `image` — spec gap and code gap reinforce each other, which is how the field escaped the prior remediation.

**Severity call**: reported major with severity uncertain; escalated to **blocker** as release manager. This is byte-for-byte the defect class the 0.5.0 pre-minor review blocked on ("the redacted gate is fail-open"), with the same producer-bug precondition the defense explicitly targets (haltija is the media-capturing producer), and a strictly worse leak than the label/href leaks G1 blocked.

**Remediation** (small, well-scoped):
1. Gate the draw: `const drawImage = !structural && w.secret !== true && typeof w.image === 'string' && w.image.startsWith('data:')`.
2. Add `image` to the withholdable-facts list in the G1 comment (src/index.ts:583), the README secret row (~line 93), and the 0.5.0 CHANGELOG fail-closed entry.
3. Extend the G1 fail-closed test (schematic.test.ts:619 area) to assert a secret record's image data URI appears nowhere in svg+legend.
4. Strongly recommended to ride the same commit: follow-up F3 below (the `verdict-secret-withheld` byte-stability fixture), so the verdict this release gated on finally gets its byte pin.

**Re-review scope after remediation**: correctness over the remediation diff only (one-line gate + test + doc-list additions); Tier 0 for the fixture addition.
