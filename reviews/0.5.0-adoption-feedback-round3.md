## Follow-ups

### → `TODO.md` (this repo)

- [ ] **(minor, unverified — correctness)** `tools/byte-stability.ts:116` — the stale-license check fires only when HEAD is byte-identical to published, so in the documented pre-tag-only workflow, drift introduced *after* 0.5.0 publishes is still excused by an armed license: `before !== after` takes the licensed branch, warns, exits 0. The instrument catches staleness exactly when there is nothing to catch and misses it when it matters (constraint-3 silent-drift territory). Mitigation already in place: `bun test` independently pins the scrub with no-leak assertions, so the residual exposure is silent byte drift, not a silent secret leak. **Fix:** key each `EXPECTED_DIVERGENCE` entry to the published version it diverges from (e.g. `{ divergesFrom: 'tosijs-floorplan-0.4.0', reason: '…' }` — the tarball name is already in scope in the loop); treat a version-mismatched license as stale (`failed = true`) so licenses self-expire at publish. Note: the stale branch itself has no test and cannot execute pre-publish (all four licensed fixtures currently diverge) — its first real execution is at the next release; add a test when reworking it.
- [ ] **(minor, unverified — blast-radius)** `tools/byte-stability.ts:61` + `src/schematic.test.ts:619` (G1) and `:644` (round-2 B1) — the `verdict-secret-withheld` byte pin and both fail-closed tests omit `text`, one of the six documented withholdable facts (label/text/value/placeholder/href/image), despite the fixture's comment claiming "every withholdable fact present". Today `text` is scrubbed only by construction (it reaches output solely through the caption chokepoint at `src/index.ts:614/623`, which the secret branch bypasses); a refactor routing `w.text` anywhere else would republish secret text with `redacted: true` stamped beside it, uncaught — the exact spec-gap/code-gap reinforcement that let `image` escape in round 2, and it propagates into tosijs's vendored copy and consumers' committed snapshots (constraint 3) before anyone notices. (The #15 test at `:698` does render a secret record with `text`, but asserts no not-contains on its content, so it would not catch this either.) **Fix:** add `text: 'leaky text'` (sentinel) to the fixture and assert its absence in both fail-closed tests. Mechanical; can ride any commit before the tag — re-review scope Tier 0 only if taken now.
