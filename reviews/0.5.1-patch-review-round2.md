## Follow-ups

### `TODO.md` (this repo; TODO.md now points to the virta board, project `tosijs-floorplan`, so file these there)

- [ ] **[correctness/security/blast-radius, minor, confirmed x3; preferably fix now] Option geometry does not fail closed.** In `src/index.ts`, options are destructured at about lines 469-477. `fontSize` is interpolated raw into `font-size="${fontSize}"` at about 801/818/839. `pad` is string-concatenated in `pinOffsetX/Y = minX + pad` (about 569-570) and in the footer `x="${minX + pad}"` (about 947). Reproduced: `{fontSize: '"/><text>FORGED</text><rect a="'}` emits a real `<text>`, a string `pad` with a viewportFixed record or a non-empty legend injects attributes, and `{pad: NaN}` writes NaN into the viewBox. The controls `minLabelHeight`, `maxCaption` and `targetSize` did not inject. Fix: at destructure, apply `const num = (v, d) => Number.isFinite(v) ? v : d` to pad, fontSize, minLabelHeight, maxCaption and targetSize, then add a hostile-set loop for `pad` and `fontSize` (with and without `within`) to the "geometry fails closed" describe block. Valid output stays byte-identical. If you do not fix this, declare options trusted in the README/CHANGELOG and scope the "Geometry fails closed" heading to records and `within`.
- [ ] **[correctness, minor] (unverified)** Add `'numeric string': '10'` to the `hostile` table in `src/schematic.test.ts` (about line 1120). This pins the announced behaviour change, so a later coercing `isFinite(+b.x)` refactor would fail a test.
- [ ] **[security, nit] (unverified)** `src/schematic.test.ts:1139`: `legend.map(e => e.text ?? e.label)` is always undefined because legend entries carry `caption`, so the assertion cannot fail. Replace it with `expect(JSON.stringify(legend)).not.toContain('hostile')`.
- [ ] **[efficiency, minor] (unverified)** Add `### Measured` under [Unreleased], for example `dist/index.js: 18,088 -> 18,314 bytes (+226, ~+1.2%; +57 gzip) — finite-bounds guard (#2739)`. - [ ] **[blast-radius, minor] (unverified)** Encode the invariant "every `${}` in an attribute is `esc()` or a finite number".
