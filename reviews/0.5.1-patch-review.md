### This repo (virta board, project `tosijs-floorplan`)
- [ ] **[security, confirmed, minor] Geometry must fail closed.** `src/index.ts` ~471-483 and 555-556. A non-numeric `bounds.x` or `bounds.y` on a `viewportFixed: true` record skips the box filter's arithmetic gate. It is then string-concatenated into the `x="..."`/`y="..."` attributes without `esc()`. Reproduced: `bounds.x = '1" onmouseover="alert(1)" a="'` injects an attribute, and a hostile `bounds.y` injects arbitrary `<text>`, which defeats the forged-glyph and `secret` guarantees.
  - Pre-existing (shipped in v0.5.0 and earlier), not introduced by this diff. Exploiting it requires record JSON that breaks its declared type.
  - Fix: require `Number.isFinite` on x, y, width, height and `within` before the `viewportFixed` short-circuit. Add a hostile-geometry test covering string, NaN and Infinity, with and without viewportFixed.
  - Valid input renders the same, so stability is unaffected. Ship it in the next patch.
  - Re-review scope: correctness + security on the remediation diff, plus a stability run.
- [ ] **[correctness, nit] (unverified)** `tools/byte-stability.ts`:
  - Lines 43-44 still say the verdict-* fixtures "diverge from 0.4.0 by license". They are byte pins now.
  - Line 15 says the preflight-seam ask "is tracked in TODO.md". Point it at board #2588.
  - Tier 0 only.
- [ ] **[efficiency, nit] (unverified)** Print the bundle size delta (published `dist/index.js` vs HEAD) from `tools/byte-stability.ts`, which already fetches the published dist. Require a CHANGELOG mention when the bundle grows. For this release the bundle is byte-identical apart from the bundler's path header.
- [ ] **[blast-radius, nit] (unverified)** `.mcp.json` registers `virta mcp` with no fallback. The hooks in `.claude/settings.json` guard with `command -v virta || true`, but the MCP server has no such guard. Either add a README contributing note that the virta server and hooks are optional and safe to decline, or move the registration to maintainer-local settings. Contributor machines only; npm consumers are unaffected.
