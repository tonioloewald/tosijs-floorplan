## Findings by severity

### Nit

1. **(correctness, unverified)** In `src/index.ts:355`, the exported `targetSizeFinding` now reads `w.bounds` before the `targetSize <= 0` short-circuit.
   - 0.5.1 checked `targetSize <= 0 || w.bounds == null || ...` first, so a disabled audit (targetSize 0) never touched the record.
   - HEAD reads `const bounds = w.bounds` in the wrapper, and `targetSize <= 0` is only checked later, inside `sizeFinding`.
   - The finder reports that a record whose `bounds` getter throws, called with targetSize 0, returns null on v0.5.1 and throws on HEAD.
   - I read the code and the order is as described. I did not re-run the throwing-getter repro.
   - Scope: only in-process getter/Proxy records are affected; plain data is unchanged. tosijs re-exports this predicate, so the change is visible to consumers. It is a new throw path, not one of the #2829 classes that are already tracked.
   - Fix: add `if (targetSize <= 0) return null` in the wrapper before reading `w.bounds`.

2. **(correctness/docs, unverified)** In `CHANGELOG.md:36`, the `esc()` bullet says "no current call site passes a non-string".
   - The flag-label path at `src/index.ts:~830-841` checks `typeof first?.label === 'string'` and then reads `first.label` again. A getter can pass the check and return a non-string on the second read.
   - The CHANGELOG's own "Not fixed" list names flag `kind`/`label` as still read more than once.
   - The claim holds only for plain data; for in-process producers it overstates the protection.
   - Fix: narrow the wording, for example: "no call site passes a non-string for plain-data input; for in-process getters (still open, #2829) this guard is the last line."

3. **(blast-radius, routed to practices, unverified)** The M1 lesson stayed in the review file.
   - The lesson: spreading a caller-supplied record to override one field drops inherited and class-backed fields, which changes a predicate's verdict.
   - It is now guarded locally by the `inherited` fixture in `tools/byte-stability.ts` and the M1 test.
   - It was not fed back to `../tosijs-coding-practices` or to the review lens prompts. Producers and consumers of this contract (tosijs's audit, which re-exports these predicates, and haltija) can repeat the mistake.
